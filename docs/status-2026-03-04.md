# SiteAnswer Project Status — 4 March 2026

## What's Been Done

### Infrastructure & Scaffolding
- Turborepo monorepo with pnpm workspaces (apps/api, apps/web, packages/shared, packages/supabase)
- Fastify 5 API with TypeBox validation, rate limiting, CORS, structured logging (pino)
- Next.js 15 App Router frontend with Tailwind CSS
- Supabase for auth, database, and storage
- 11 database migrations deployed (schema, RLS, all feature tables)
- Zod schemas in packages/shared for type safety across apps
- Vercel deployment (API at siteanswer-api.vercel.app, Web at siteanswer-web-three.vercel.app)
- CI with GitHub Actions

### Authentication & Users
- Supabase Auth with email/password registration + email confirmation
- JWT verification in API (Fastify auth plugin)
- Auth routes: check-email (MX validation), setup-profile, /me
- Frontend login + register pages
- New users redirected to onboarding after signup
- Role-based access (admin vs member)

### Organisation Management
- Full org CRUD (name, timezone, business hours, escalation config, GDPR settings)
- Settings page with all config options
- Test call feature (POST /organisations/test-call)
- Phone number setup (ElevenLabs native phone linking)

### ElevenLabs AI Agent
- Agent provisioning per org (creates ElevenLabs conversational agent)
- Dynamic system prompt builder assembles from: org data, KB entries, scripts, screening rules, business hours
- Business hours awareness — prompt includes current time, timezone, and whether currently in/out of hours
- After-hours script automatically included when outside business hours
- Agent sync service — KB/script changes trigger prompt rebuild
- All 10 tool functions implemented and wired:
  - `lookup_caller` — GHL contact lookup + screening classification
  - `create_new_contact` — Creates contact in GHL with tags
  - `check_calendar` — Returns available appointment slots
  - `book_appointment` — Books appointment
  - `send_sms` — Sends SMS via GHL (when CRM connected)
  - `escalate_to_builder` — Triggers escalation (SMS + call)
  - `get_knowledge` — KB search
  - `log_message` — Logs to call record
  - `send_whatsapp` — Sends WhatsApp template message
  - `record_payment_outcome` — Records payment chase outcome
  - `tag_call_outcome` — Tags call for screening/analytics
